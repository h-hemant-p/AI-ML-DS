## Feature Scaling

* Feature scaling ek yesi process hai jo ek same range ke andar lake sabhi numbers ko rakh degi, so that ML models confused na hon bade aur chhote numbers ke bich me.
* For Example - if we have 2 features "height"(180 m) and "study time"(4 h), here our ML model will confused becase one feature has  big values and one has small values. so, here we will apply feature scalling on height and we'll convert values in small range.

  * Min Max Scaler
