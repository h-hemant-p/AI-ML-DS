## Exploratory Data Analysis


1. Viewing the Data
   * head(), tail(), shape(), info() etc.
2. Summary Stastics
   * mean, median, mode, std, min, max, quartiles etc.
3. Value Counts
   * Unique values etc.
4. Missing Value Analysis
5. Visualizations
   * Histograms → distributions of values
   * Boxplots → outliers and spread
   * Barplots → camparisons of categories
   * Correlation heatmaps → linear relationships between numerical features
   * Scatterplots → bivariate relationships
